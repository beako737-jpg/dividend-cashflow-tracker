# dividend-cashflow-tracker

複数の証券会社からダウンロードできる公式「配当金・分配金履歴」CSVを読み込み、**実際に受け取った配当金・分配金を、月次・年次の推移、銘柄別ランキング、口座区分（NISA成長投資枠／NISAつみたて投資枠／特定口座／一般口座）別の内訳として集計した1つのオフラインHTMLレポート**を1コマンドで生成するCLIツールです。証券会社のマイページはそれぞれ自社の履歴しか見せてくれず、複数口座を使っていると「今年トータルでいくら配当をもらったか」を把握するために画面を何度も行き来する必要があります。加えて、NISA口座の受取分は非課税、特定口座・一般口座の受取分は既に約20.315%源泉徴収された後の金額という違いがあるにもかかわらず、それを区別して合計してくれるツールはほとんどありません。本ツールはこの「受取キャッシュフローの全体像」を可視化することに専念しています。

**[stock-tax-summary](https://github.com/beako737-jpg/stock-tax-summary)との違い**: stock-tax-summaryは確定申告のための株式・ETF譲渡損益＋配当所得の「税務上の合算値」を扱うツールです。本ツールはそれとは別物で、税務目的ではなく**資産形成の観点での配当・分配金の受取実績そのもの**（いつ・どの銘柄から・どの口座区分でいくら受け取ったか）を可視化します。

- 依存ライブラリなしで動作（標準ライブラリのみ。HTML生成も自前テンプレート）
- 証券会社ごとに列名が違っても、ファイルごとに個別の`mapping`を指定できる（[broker-csv-consolidator](https://github.com/beako737-jpg/broker-csv-consolidator)や[nisa-quota-tracker](https://github.com/beako737-jpg/nisa-quota-tracker)と同じ「複数ファイル×個別マッピング」の仕組み）
- 複数の証券会社のCSVを1つのレポートに統合（nisa-quota-trackerと違い、NISA以外の特定口座・一般口座分も含めて全件を集計対象にします -- 受取キャッシュフローの全体像を見るのが目的のため、非NISA分を捨てません）
- 口座区分（NISA成長投資枠／NISAつみたて投資枠／特定口座／一般口座）を自動判定し、非課税分・課税(税引後)分を分けて集計
- 月次・年次の受取総額推移をグラフ化（複数年のデータがあれば、すべての年をそのまま表示。特定の年だけを取捨選択することはありません）
- 銘柄別の受取金額ランキング・全体に占める比率
- 年×口座区分の集計表、証券会社別サマリー、受取明細（開閉式）
- レポートはブラウザで開くだけ、外部通信なし（チャートも自前SVG、外部CDNに依存しない）

## レポートに含まれる内容

- 受取総額（全期間）／当年の受取総額（前年比）／NISA分（非課税）／課税口座分（特定・一般、税引後）／銘柄数、のサマリーカード
- 月次の受取推移（NISA分・特定口座分・一般口座分の積み上げ棒グラフ、ホバーで月ごとの内訳を確認可能。配当・分配金が実際にあった月のみ表示）
- 年次の受取推移（同じく積み上げ棒グラフ、複数年比較用）
- 銘柄別の受取金額ランキング（銘柄コード・金額・全体比率）
- 口座区分別の内訳（非課税／課税(税引後)のバッジ付き）
- 年×口座区分の集計表（複数年のデータがあっても年別にすべて表示）
- 証券会社別サマリー（対象期間・銘柄数・件数・受取合計）
- 受取明細テーブル（開閉式、受取日・証券会社・銘柄・口座区分・金額）

## クイックスタート（サンプルデータ）

SBI証券・楽天証券の2社を併用しているケースを想定した合成サンプルCSVが`sample_data/`に入っています（個人情報は含みません。銘柄名・数値はすべて架空のものです）。

- `sbi_dividends.csv` — SBI証券、2025年6月〜2026年6月分（デフォルトの列名マッピングをそのまま使用）

## 自分のデータで使う

1. 証券会社のマイページ（SBI証券「My資産」→「配当金・分配金履歴」→CSVダウンロード、楽天証券「配当・分配金」履歴画面など）から、**銘柄名・受取日・受取金額・口座区分の列を含む**配当金・分配金履歴CSVをダウンロード
2. 使うファイルをまとめた設定JSONを作る（`sample_data/sample_config.json`が実例）

   ```json
   {
     "as_of_year": 2026,
     "sources": [
       {
         "broker": "○○証券",
         "csv": "oo_dividends.csv"
       },
       {
         "broker": "△△証券",
         "csv": "delta_dividends.csv",
         "mapping": {
           "date": "受取日",
           "code": "コード",
           "name": "ファンド名",
           "account": "口座区分",
           "amount": "受取金額(円)"
         }
       }
     ]
   }
   ```

   - `as_of_year`: 集計基準年（省略時は各CSVに含まれる最新の年を自動使用）。サマリーカードの「当年の受取総額」「前年比」の基準になります
   - `broker`: 出力に使うラベル（省略時はCSVファイル名を使用）
   - `csv`: 入力CSVのパス（設定JSONファイルからの相対パス）
   - `mapping`: デフォルトの列名マッピング（`受渡日 / 銘柄コード / 銘柄名 / 口座 / 受取額（税引後）`）を上書きしたいキーだけ書く。`code`（銘柄コード）は投資信託などコードが無い銘柄のために省略可能（`"code": ""`にするか、キー自体を書かない）
   - 口座区分の値は「NISA（成長投資枠）」「NISA（つみたて投資枠）」「特定」「一般」に類する表記を自動認識します。表記が一致しない行も**スキップせず**「口座区分 不明」として金額はきちんと合計に含めた上でカウントします（実行時にコンソールへ警告が表示されるので、必要なら`dividend_cashflow_tracker.py`冒頭の`NISA_GROWTH_LABELS`等に実際の表記を追加してください）

3. `python dividend_cashflow_tracker.py --config config.json --out report.html`

### うまく変換できない場合

- 列名が見つからないと`column 'X' for field 'Y' not found`というエラーで止まります。`mapping`のキーとCSVの実際のヘッダーを確認してください。
- 日付が自動判定できないと`could not parse date value`というエラーで止まります。`datetime_format`にその証券会社の形式を明示的に指定してください（例: `"%Y/%m/%d"`）。
- 口座区分の表記がどのラベル集合にも一致しないと「口座区分 不明」に分類されます（金額は合計から除外されません）。想定外に多くの行がここに分類される場合は、コンソールに表示される実際の表記を確認し、スクリプト冒頭のラベル集合に追加してください。

## 重要な前提（数値を信頼する前に必ずお読みください）

**NISA分と特定・一般口座分は、税金の扱いが異なる金額を単純合算しています。** NISA口座（成長投資枠・つみたて投資枠）で受け取った配当金・分配金は非課税で、CSV上の金額がそのまま手取り額です。一方、特定口座・一般口座分は証券会社が源泉徴収した後の金額（税引後、約20.315%控除済み）がCSVに記載されているのが一般的です。つまり「NISA分」と「特定・一般口座分」を単純に比較すると、税引前ベースでの投資効率を見誤る可能性があります（本ツールはこの違いをレポート内で注記していますが、税引前金額への逆算などは行っていません）。

## このツールが「やらないこと」

「今後いくら配当を受け取れそうか」「増配率から将来の受取額を予測する」「どの高配当銘柄を買うべきか」といった投資助言や将来予測は行いません。各証券会社・証券情報サービスの銘柄スクリーニング機能はこうした将来予測に強みがありますが、本ツールは**過去に実際に受け取った配当金・分配金の実績を可視化する**ことに専念しています。

## 免責事項

このツールは証券会社の公式CSVに実際に記載された配当金・分配金の受取実績を集計・可視化するものであり、投資助言や税務相談ではありません。口座区分の自動判定や税引後/非課税の分類に誤りが生じる可能性があります。確定申告など税務目的の集計には使用せず、正式な数値は証券会社が発行する年間の取引報告書・支払通知書と必ず突き合わせてください（税務目的の損益通算には[stock-tax-summary](https://github.com/beako737-jpg/stock-tax-summary)をご利用ください）。
